
# Formula 1 Info

Check last Formula info in one place!


## Run Locally

Clone the project

```bash
  git clone https://github.com/instanceoff/formula-one-info.git
```

Go to the project directory

```bash
  cd formula-one-info
```

Install dependencies

```bash
  bun install
```

Start app for development

```bash
  bun dev
```


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`RAPIDAPI_KEY`

You can get it from [this website](https://dashboard.api-football.com)
